# 🐾 탱크 서바이벌

Claude Code가 일하는 동안 사무실 사람들과 터미널에서 한 판 하는 귀여운 탱크 대전 모드예요.
각자 동물 탱크(🐱🐶🐸🐼🐷🐵🐻🐨)를 몰고, 에너지(♥ 5칸)를 다 잃으면 탈락, 마지막까지 살아남으면 승리 🏆

## 준비물

- Claude Code (터미널 또는 데스크톱 앱)
- Node.js 18 이상 (`node -v`로 확인)
- 같은 사무실 네트워크

## 설치

비공개 저장소라서 먼저 두 가지가 필요해요.

1. 저장소 주인(torder-backend-peter)이 GitHub에서 나를 이 저장소에 초대해야 해요.
2. 내 컴퓨터에 GitHub 로그인이 되어 있어야 해요. 한 번만 하면 돼요.

```
gh auth login
gh auth setup-git
```

그다음 Claude Code 입력창에서:

```
/plugin install tank-survival --marketplace torder-backend-peter/tank-survival
```

`Add marketplace?`가 뜨면 `y`, 설치 범위는 맨 위(user)를 Enter로 고르면 돼요.

터미널에서 바로 설치하려면:

```
claude plugin install tank-survival --marketplace torder-backend-peter/tank-survival
```

## 명령어

| 명령어 | 하는 일 |
| --- | --- |
| `/tank host [비번]` | 방 만들기. 내 IP와 친구용 참가 명령어를 알려주고 클립보드에 복사해요 |
| `/tank host [비번] 큰맵` | 넓은 맵으로 방 만들기. 비번과 순서는 상관없어요 |
| `/tank join IP [비번]` | 친구 방 들어가기 |
| `/tank name 이름` | 게임에 나올 내 이름 (최대 8자) |
| `/tank leave` | 방 나가기 |
| `/tank` | 게임 화면 열기 |

Claude가 답하는 중에도 바로 실행돼요.

## 조작

게임 화면을 한 번 클릭하면 키가 게임으로 가요. Esc를 누르면 입력창으로 돌아와요.

- 이동: 방향키 (또는 WASD)
- 발사: 스페이스 (또는 J, F)

## 아이템

🍓 에너지 +2칸 · 🔥 8초 연사 · 🐢 6초 방패 · 💣 강한 포탄 3발 (강철 벽도 부숴요) · 👟 8초 속도업

## Claude 상태

- 🔨 내 Claude가 작업 중
- 🔔 Claude가 답변을 끝냄. 확인하러 갈 수 있게 내 탱크가 💤 상태로 최대 30초 동안 맞지 않아요 (그동안은 쏠 수 없어요). 게임 키를 누르면 바로 풀려요.

다른 사람 화면에도 이 아이콘이 보여요.

## 알아둘 것

- 방장 컴퓨터가 게임 판정을 맡아요. 방장이 나가면 방이 닫혀요.
- 방은 TCP 7777 포트로 열려요. 처음 열 때 macOS 방화벽이 물어보면 허용해주세요.
- 한 판은 최대 2분(큰 맵은 2분 30초)이고, 시간이 다 되면 에너지가 가장 많은 사람이 이겨요. 2명부터 시작하고, 혼자일 때는 연습 모드예요.

## 맵

| 맵 | 크기 | 아이템 | 필요한 화면 폭 |
| --- | --- | --- | --- |
| 보통 (기본) | 26×13 | 최대 3개 | 가로 54칸 |
| 큰맵 | 38×17 | 최대 5개 | 가로 78칸 |

화면이 좁으면 맵 대신 넓혀달라는 안내가 나와요. 오른쪽 게임 창의 왼쪽 경계를 끌어 넓혀주세요.
방장과 참가자 모두 같은 버전이어야 해요. 다르면 "모드 버전이 달라요" 안내가 나와요.
